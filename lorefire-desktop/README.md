# Lorefire desktop (2E)

This folder is the NativePHP app. Install and run from here. Parent [README](../README.md) covers product setup.

## How this tree stays legal

Lorefire 2E implements original UI wording, mechanical tables, and bibliographic pointers. It does not ingest official prose, PDFs, OCR, or RAG.

Allowed ingest:

- User cards (short original summaries you type with the book open)
- Table law (this table's house rulings)
- WhisperX session transcripts
- FG&G (fan-generated and OGL material) only after an explicit opt-in plus the OGL row

Forbidden: official PDF/rulebook importers, handbook excerpts, 1E books, 1995 revised pagination as live core.

`death_mode` is `phb_zero` (at 0 hit points the character is slain). Dual-class house switch is TABLE LAW, not 1989 PHB core.

## Enable an extra 2E pack

Extra packs (Tome of Magic, Legends & Lore 2E, Monster Mythology, Arms and Equipment, DMGR1/2, later MCs except Forgotten Realms, Monstrous Manual 1993) seed **off**.

1. Open **Settings**, then **Table Law and Sources**.
2. Find the pack (filter Extra 2E packs).
3. Click **Enable**.

LOOKUP may then name that pack. It still will not ingest official prose. Fill cards from the physical book. Later 2E / Player's Option / 1995 revised stay off for pagination even if you browse them.

## Cards and citations

Card slots are empty plus a couple of user stubs. Fields: source code, short original effect summary, citation work/year/pages/topic, user verified. Citations are work, year, pages, topic. There is no excerpt column. Do not paste book text.
